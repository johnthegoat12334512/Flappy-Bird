# Lantern Moth

A one-button flying game. Flap a moth through the gaps between lantern-lit pine trunks at dusk.

## Play

Open `index.html` in any browser. No build step or dependencies.

- **Flap:** Space, ↑, W, click or tap
- **Pause:** P (also pauses when the tab is hidden)

Each trunk you pass scores a point. Your best score is saved in the browser.
